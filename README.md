# Tira-Time · Placar ao vivo

Página pública do placar ao vivo dos jogos do app Tira-Time.
Abra com o código do jogo: `https://kavictech.github.io/tira-time-placar/?c=CODIGO`

Gerada automaticamente a partir do app (`tool/build_placar.py`). A página só lê o placar
pela chave pública do projeto; nenhum dado privado fica aqui.
